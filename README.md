# webacy-skills

Agent-agnostic packaging of the [Webacy](https://webacy.com) onchain risk engine.
Webacy runs a hosted MCP server (`https://api.webacy.com/mcp`, HTTP streamable,
`x-api-key` auth) whose tools work in any MCP client. This repo packages Webacy for
any agent or UI, favoring none, with:

1. **Connection configs** for Claude Code, Claude Desktop, Cursor, Codex, and generic
   MCP clients.
2. **A portable agent guide** — when to use Webacy and how to read its results.

## Layout

- `src/` — canonical, hand-edited sources: `meta.yml`, `guide.md`, and one
  `connect/*.md` per client.
- `skills/webacy/SKILL.md` and `AGENTS.md` — **generated**; do not edit by hand.
- `scripts/build.mjs` — fetches the live tool list and regenerates the artifacts.

## Generated files

`skills/webacy/SKILL.md` and `AGENTS.md` are generated by `scripts/build.mjs`, which
fetches the live tool list from `api.webacy.com/mcp` and injects it into the guide. A
weekly GitHub Action (`.github/workflows/sync.yml`) reruns the build and opens a PR
whenever the output drifts. The Action needs a `WEBACY_API_KEY` repository secret.

**Edit `src/`, never the generated files.**

## Build locally

```bash
npm install
WEBACY_API_KEY=your_key npm run build
```
